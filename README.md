# Capstone-Design-4-2

## 프로젝트 소개

### 개인정보 노출 자동 탐지 및 마스킹 시스템

문서, 소스코드, 로그 등에 포함된 개인정보를 자동으로 탐지하고,
탐지된 개인정보를 마스킹 또는 가명처리하는 시스템을 개발한다.

정규식 기반 패턴 매칭과 NER(개체명 인식)을 결합한 이중 탐지 방식을 사용하여
개인정보 탐지 정확도를 높이는 것을 목표로 한다.

원본 파일은 직접 수정하지 않고 그대로 보존하며,
개인정보가 마스킹된 처리본을 별도의 파일로 생성하여 저장하는 방식으로 구현한다.

## 팀원 역할

- 박주아: 정규식 기반 개인정보 탐지 모듈 개발
- 이나연: NER 기반 개체명 인식 탐지 모델 개발 및 학습·튜닝
- 최동명: 개인정보 마스킹 및 가명처리 모듈 개발
- 김재민: 원본 보존 및 점검·처리 이력관리 모듈 개발
- 김진웅: 파일 입출력 및 실행 프로그램(UI/CLI), 메인 파이프라인 개발

## 설치 및 실행 방법

### 필요 환경

- Windows
- Python 3.10 이상 (설치 시 "Add python.exe to PATH" 체크)
- 처음 설치할 때 인터넷 연결 필요

### 설치 (처음 한 번)

저장소 맨 위 폴더의 `setup.bat`을 더블클릭한다.

- `.venv` 폴더를 만들고 필요한 라이브러리(`requirements.txt`)를 그 안에 설치한다.
- 설치가 끝나면 테스트가 자동으로 실행된다. 마지막에 `통과`가 나오면 정상이다.
- `requirements.txt`에 라이브러리가 추가되었을 때만 다시 실행하면 된다.

### 실행

`run.bat`을 더블클릭하면 프로그램(GUI)이 실행된다.

1. **파일 선택** 또는 **폴더 선택**으로 처리할 대상을 고른다. 폴더는 하위 폴더까지 지원 형식 파일을 모두 목록에 보여준다.
2. 목록에서 처리할 파일만 체크한다. (**전체 선택 / 전체 해제** 가능)
3. 처리 방식을 고른다.
   - **마스킹**: 개인정보를 가린 처리본을 만든다.
   - **점검만**: 처리본 없이 개인정보 위치만 확인한다.
4. **실행**을 누른다. 파일을 선택하면 아래에 탐지 위치가 원문 대신 가린 문장으로 표시된다.
5. **결과 폴더 열기**로 처리본을, **이력 보기**로 처리 이력을 확인한다.

지원 형식: docx(본문·표·머리글·바닥글, 서식 유지), txt·log·csv·json·md 및 소스코드(py, java, js 등) 텍스트 파일

### 결과 저장 위치

| 폴더 | 내용 |
|---|---|
| `output/` | 마스킹 처리본 (`원본이름_masked.확장자`). 원본 파일은 수정하지 않는다. |
| `logs/history.jsonl` | 점검·처리 이력 |

`output/`, `logs/`, `.venv/`는 `.gitignore`에 포함되어 저장소에 올라가지 않는다.

### 명령어로 실행 (선택)

저장소 맨 위 폴더에서:

```bash
.venv\Scripts\python app/main.py 파일또는폴더경로            # 마스킹
.venv\Scripts\python app/main.py 파일또는폴더경로 --check    # 점검만
.venv\Scripts\python app/tests/run_tests.py                  # 파이프라인 테스트
.venv\Scripts\python -m unittest discover -s tests -p "test_*.py"   # 이력관리 모듈 테스트
```

메인 파이프라인 구조와 모듈 연결 방식은 [app/docs/DEVELOPMENT.md](app/docs/DEVELOPMENT.md) 참고

## 주요 기능 및 개발 내용

### 개인정보 탐지

정규식 기반 탐지 모듈과 NER 기반 탐지 모듈을 이용하여
문서, 소스코드, 로그 등에 포함된 개인정보를 탐지한다.

두 탐지 모듈의 결과는 다음과 같은 형식으로 통일한다.

```python
{
    "seg_id": 0,
    "start": 15,
    "end": 29,
    "type": "RRN",
    "text": "990101-1234567"
}
```

- `seg_id`: 개인정보가 탐지된 세그먼트 식별값
- `start`: 개인정보 시작 위치
- `end`: 개인정보 끝 위치
- `type`: 개인정보 유형
- `text`: 탐지된 원본 문자열

### 개인정보 마스킹

탐지 결과를 이용하여 주민등록번호 등 개인정보를 마스킹한다.

현재 주민등록번호 및 외국인등록번호에 대해
뒷자리 일부를 별표(`*`)로 변환하는 기능을 구현하고 있다.

### 처리본 생성

원본 파일 자체는 수정하지 않는다.

탐지 및 마스킹이 완료된 결과를 별도의 처리본으로 생성하여 저장하고,
원본 파일은 그대로 유지한다.

### 점검 및 처리 이력관리

개인정보 처리 과정에서 다음 정보를 기록한다.

- 처리 시간
- 원본 파일명
- 마스킹 처리본 경로
- 개인정보 탐지 건수
- 처리 방식
- 처리 성공/실패 상태
- 오류 발생 시 오류 내용

저장된 점검 및 처리 이력을 다시 조회할 수 있도록 구현한다.

### 메인 파이프라인

Python 기반으로 각 모듈의 함수를 순서대로 호출하는 방식으로 구성한다.

현재 예정된 전체 처리 흐름은 다음과 같다.

```text
파일 로드
    ↓
정규식 및 NER 개인정보 탐지
    ↓
탐지 결과 병합
    ↓
개인정보 마스킹
    ↓
마스킹 처리본 생성 및 저장
    ↓
점검 및 처리 이력 기록
```

## 현재 결과의 한계와 향후 개선 제안

현재 각 기능을 모듈 단위로 개발하고 있으며,
NER 탐지 모듈과 메인 파이프라인을 포함한 전체 시스템 통합은 진행 중이다.

초기 계획에서는 처리 전 원본 파일을 별도로 백업하고
필요 시 복구하는 방식을 고려하였다.

구현 과정에서 원본 파일 자체를 수정하지 않고 그대로 보존하면서
마스킹된 처리본을 별도로 생성하는 방식으로 변경하였다.

따라서 별도의 원본 복구 기능은 현재 구현 대상에서 제외하고,
향후 필요성에 따라 추가 검토할 예정이다.
